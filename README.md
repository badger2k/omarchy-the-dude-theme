# The Dude

A dark [Omarchy](https://omarchy.org) theme for *The Big Lebowski*: rug-dark browns, White Russian cream, Gutterballs gold, bowling-alley neon teal and Jesus Quintana purple.

![The Dude preview](preview.png)

## Install

```
omarchy theme install https://github.com/badger2k/omarchy-the-dude-theme
```

The backgrounds are original illustrations made for this theme.
